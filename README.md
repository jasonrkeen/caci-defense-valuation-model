# CACI International Defense Technology Valuation & Intelligence Model

A Python-based equity valuation, defense technology intelligence, risk analytics, forecasting, risk modeling, and automated reporting project for **CACI International Inc. (NYSE: CACI)**.

**Author:** Jason Keen  
**Contact:** [LinkedIn](https://www.linkedin.com/in/jason-keen-1887b4218)

This project combines market data, peer benchmarking, discounted cash flow valuation, defense contractor stress testing, Monte Carlo simulation, GARCH/EWMA volatility and VaR modeling, defense equity factor exposure modeling, analyst estimate collection, government spending signals, defense macro analysis, source auditing, news intelligence, expected return modeling, run-to-run change detection, and a final LinkedIn-ready PDF research report.

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
```

Optional but recommended for true GARCH volatility modeling:

```powershell
python -m pip install arch
```

Run the full pipeline:

```powershell
python -m src.main
```

The run will download market data, generate CSV outputs, create charts, run valuation and risk models, and build the final PDF report.

### 2. GARCH / EWMA Volatility and VaR Model

The project includes a dedicated volatility and downside-risk module.

The model attempts to use a true **GARCH(1,1)** model when the `arch` package is installed and enabled. If GARCH fitting is unavailable or fails, it falls back to an EWMA volatility model.

- Parametric VaR
- Primary model VaR
- EWMA reference VaR
- Expected shortfall

- Kupiec proportion-of-failures test results

### 3. Defense Equity Factor Exposure Model

The factor model estimates how CACI daily returns relate to market, defense, technology, interest-rate, and volatility/risk-sentiment factors.

Factor proxies are configured in `src/config.py`:

```text
^GSPC = S&P 500 market factor
ITA   = Aerospace and defense factor
XLK   = Technology factor
^TNX  = Interest-rate factor
^VIX  = Volatility / risk-sentiment factor
```

The model uses ordinary least squares regression to estimate:

- Annualized alpha
- Factor model R-squared
- Adjusted R-squared
- Annualized residual volatility
- Market factor sensitivity
- Aerospace and defense factor sensitivity
- Technology factor sensitivity
- Interest-rate factor sensitivity
- Volatility / risk-sentiment factor sensitivity
- Simple correlation versus each factor
- Descriptive annualized factor contribution

Factor model outputs include:

```text
factor_price_history.csv
factor_return_history.csv
factor_exposure_summary.csv
factor_regression_results.csv
factor_correlation_summary.csv
factor_contribution_summary.csv
```

The factor exposure chart is saved as:

```text
factor_exposure_chart.png
```

This section helps distinguish whether CACI behaves more like a broad-market stock, a defense-sector stock, a technology-adjacent stock, a rate-sensitive equity, or a risk-sentiment-driven equity.

### 7. Defense Contractor Stress Testing

The stress-testing module evaluates how CACI fair value changes under downside scenarios tied to government contracting, funding timing, margin pressure, recompete risk, revenue slowdown, and discount-rate pressure.

Stress cases include:

- Base case
- Federal budget delay
- Continuing resolution / award timing delay
- Higher WACC / rate shock
- Margin compression
- Contract recompete loss
- Revenue growth slowdown
- Combined downside case

Stress-test outputs include:

```text
stress_test_assumptions.csv
stress_test_summary.csv
stress_test_bridge.csv
stress_test_score.csv
```

Key stress-test metrics include:

- Stress Resilience Score
- Average stress downside
- Worst stress downside
- Worst stress case
- Fair value per share by stress case
- Dollar impact versus base case
- Percent impact versus base case
- Stress signal
- Valuation bias

The Stress Resilience Score now flows into both the final **Defense Technology Intelligence Score** and the **Expected Return Model**. When stress resilience is weak, the expected-return model applies a stress resilience haircut to the final risk-adjusted expected return.

Stress-test charts include:

